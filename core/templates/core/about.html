About

This project is a starting point for building with Django. It includes:

  • A core app for views, URLs, and templates
  • A shared base template that all pages extend
  • App-level URL routing included from the project URLconf
  • Static file handling for stylesheets and assets

Add new pages by creating a view, a template that extends the base layout, and a URL pattern in core/urls.py.
